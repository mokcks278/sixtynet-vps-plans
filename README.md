## 住宅 IP 不开 80/443，到底卡住谁

这条限制影响面比很多人想的大，不只是“不能建站”这么简单。

**会卡住的情况：**

- 直接用 Nginx、Apache、Caddy 对外提供 HTTP/HTTPS 服务，浏览器访问默认走 80/443，直接连不上；
- Let's Encrypt 的 HTTP-01 方式签证书，验证请求打的是 80 端口，签不下来；DNS-01 方式不受影响；
- 大部分 CDN 回源默认填 80 或 443，回源会失败，需要改成自定义回源端口；
- 依赖 80/443 的健康检查、Webhook 回调、部分支付接口的异步通知。

**不受影响的情况：**

- 代理、隧道、frp 这类自定义端口转发；
- 数据库、消息队列、SSH、API 走非标端口的服务；
- 流媒体解锁、社媒运营、跨境电商后台这类以“访问别人”为主、不以“被别人访问”为主的用途；
- 用反向代理把 80/443 落在另一台机器上，这台只做后端。

如果你的业务核心是“用这个 IP 的身份”，住宅 IP 的价值远大于端口限制带来的麻烦；如果核心是“让外面访问进来”，这组产品基本可以直接排除，去看 LAX 标准系列。

## 线路怎么选：AS9929、CN2 和普通洛杉矶差在哪

按第三方测评的实际路由结果，SixtyNet 的洛杉矶机器在国内方向的表现大致是这样：

- 电信去程走 CN2 直连洛杉矶，回程部分路由隐藏但确认走 CN2；
- 联通回程走 AS10099 + AS9929，属于联通的高端国际线路；
- 移动回程强制走电信 CN2。

三网平均延迟在 170–180ms，电信最低到过 165ms，对美西机房属于正常水平。官方屏蔽了 PING，第三方测评拿不到完整延迟数据，这个数字也只能当参考。

AS9929 系列的价值就在这里。它把联通方向单独优化，适合用户以联通宽带为主、或者业务对联通线路质量敏感的场景。代价是退款只退余额、机器拒绝一切外部探测（调试时 ping 不通、端口扫不到都属于正常现象，别当成故障）。

普通 LAX 系列走的是 163 高防直连加 CN2 GIA 回程的组合，带 DDoS 防护。对多数人来说这个组合已经够用，价格也更好算。

## 高性能 VPS 该看哪几个参数：一份可以套用的判断规则

“高性能”在 2026 年已经被这批厂商的落地页统一成了几条硬指标：AMD EPYC 或 Ryzen 9、NVMe、DDR5、不超售的独享 vCPU、G 级到数十 G 级的端口。参数之外，真正决定你买对买错的是一个分岔：

**负载能不能并行。**

Cloudzy 在自家页面上把这条规则写得很清楚：单线程或延迟敏感的负载（外汇 EA、MT4/MT5、Minecraft 和 CS 服务器、插件多的 WordPress、Discord 机器人、自建 Node 服务）选高主频档；能并行的负载（构建农场、批处理、多租户数据库）选常规 CPU 档，核心数比主频值钱。这家还提到同档位的高频和常规 CPU 价格相同，没有加价。

RamNode 在 Premium NVMe 产品页给了按场景的配置建议，其中一条有参考价值：跑 Kubernetes 的多服务环境，4 vCPU / 8G 是起步线，2 核 4 核只适合学习和实验。数据库场景它建议小中型用 2 核 3G 起，生产环境并发查询多用 4 核 8G。

把这两条搬到 SixtyNet 的套餐上：

- 跑单个高并发 Web 服务、代理、机器人：LAX-STARTER 的 2 核 2G 够；
- 跑数据库或多站点、容器编排：LAX-MICRO 的 4 核 4G 是合理起点；
- 编译、批处理、CI runner：直接看 8 核的 LAX-MEDIUM，核心数在这里比单核频率重要；
- 需要大内存跑多租户或缓存层：LAX-LARGE 的 16G。

需要注意的是，SixtyNet 官网没有标注具体 CPU 型号和是否独享核心。第三方测评提到用过 AMD EPYC 7002 系列和 EPYC 7K62，两者都属 EPYC，但代际不同，单核性能有差距。下单前如果对型号敏感，值得先问一句当前批次的 CPU。

## 真实总成本：备份、快照和流量这三项最容易漏算

标价之外的加价项，各家差异很大，买之前算清楚能省不少麻烦。

**备份和快照。** Arct Cloud 的自动每日备份按月费的 20% 收，手动快照 $0.04/GB/月；Contabo 把 5 个快照直接写进标配不另收费。SixtyNet 官网的套餐页没有列备份和快照的独立价格，购买前建议在控制面板或客服处确认这一项是否包含、包含几个。

**流量口径。** 三家的说法完全不同：Contabo 标入站出站均不限量至 1 Gbit/s，但明确保留对异常高流量限速的权利，适用公平使用政策；Arct Cloud 只计出站流量，入站免费，nano 和 micro 档 5TB、更大档 10TB；SixtyNet 直接给固定额度，5TB 到 40TB 按档递增。三种口径不能统一理解成“都不限流量”，Contabo 那种是“不限但有边界”，另两家是“明码标量”。

**计费周期。** Contabo 最短合约 1 个月，预付方式没有取消通知期；Cloudzy 14 天无理由退款、下单不需要信用卡；XServer 的低价绑 36 个月。SixtyNet 的 LAX 系列是年付，AS9929 系列退款只退余额。长合约换低价是行业通行做法，看清楚最短合约期和退款窗口，比看月起价有用。
